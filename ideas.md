# PsychMind Design Directions Archive

## Product Brief

PsychMind is a front-end psychology study website that combines nine weekly learning modules with sixty practice questions. The original brief called for a premium interface, refined typography, advanced interactive motion, clearly separated knowledge modules, and a strong focus on UI craft.

---

## Direction One: Neural Pathways

### Design Movement

A scientific visual language inspired by neural-network diagrams and medical illustration, combining dark surfaces with fluorescent signals.

### Core Principles

1. A dark background with fluorescent accents can evoke synaptic activity.
2. Connected lines and nodes can communicate relationships between knowledge areas.
3. Glowing effects and particle motion can create a deep, scientific atmosphere.
4. Clear information hierarchy should use light and contrast to guide attention.

### Color Philosophy

- Deep blue-black `#0a0e1a` represents the interior of the mind.
- Cyan `#00f5d4` represents neural signals.
- Violet `#7b2ff7` represents awareness and thought.
- Warm white `#e8e6e3` preserves content readability.

### Layout and Interaction

A vertically scrolling page treats each module as a distinct cognitive region connected by particles and pathways. Floating neural particles, luminous card edges, pulse animation, scroll parallax, and a hover-based synapse-activation response create the proposed interaction language.

### Typography

- Display: Space Grotesk
- Body: Inter

## Direction Two: Cognitive Canvas

### Design Movement

A scholarly approach inspired by Bauhaus restraint and the quiet texture of wabi-sabi study materials, using generous whitespace and precise editorial composition.

### Core Principles

1. White space lets knowledge breathe.
2. Type scale and weight create a careful reading rhythm.
3. Gentle warm colors support sustained focus.
4. Modular cards keep each concept distinct and organized.

### Color Philosophy

- Paper white `#faf8f5` creates a premium study surface.
- Ink `#1a1a2e` provides calm, stable contrast.
- Ochre `#c4704b` supplies a warm academic accent.
- Soft gray `#e8e4df` separates information without visual noise.

### Layout and Interaction

An asymmetric magazine grid pairs fixed navigation with staggered content cards. Hand-drawn separators, refined underlines, highlight marks, and bookmark-style chapter labels support a physical-reading metaphor. The interaction system uses page-turn transitions, bookmark expansion, small hover lift, soft shadow changes, and line-by-line text reveals.

### Typography

- Display: Playfair Display
- Body: Source Sans 3

## Direction Three: Mindscape

### Design Movement

A study system inspired by Swiss International Style and modern data visualization, combining bold color blocks with a precise grid for an academic but visually expressive outcome.

### Core Principles

1. Bold color regions distinguish the course modules.
2. A disciplined grid preserves alignment and order.
3. Icons and visualization make abstract concepts easier to recognize.
4. High contrast and clear information hierarchy support study tasks.

### Color Philosophy

- A white surface keeps the application professional and clean.
- Week 1: deep blue `#1e3a5f`.
- Week 2: teal `#0d7377`.
- Week 3: amber `#d4770b`.
- Week 4: indigo `#4a3f8f`.
- Week 5: coral red `#c44536`.
- Week 6: forest green `#2d6a4f`.
- Week 7: gold `#b8860b`.
- Week 9: deep violet `#5c2d91`.
- Week 10: sky blue `#2196f3`.
- Body ink: `#2d3436`.

### Layout and Interaction

A horizontal top navigation leads into full-width color-block sections, with multi-column grids inside each learning area. Module icons, continuous progress feedback, staggered scroll entrances, elastic color-block movement, answer-confirmation effects, and smooth progress fills form the interaction system.

### Typography

- Display: DM Sans
- Body: IBM Plex Sans

---

## Original Final Choice: Mindscape

Mindscape was originally selected because module-specific color identities are well suited to nine psychology chapters; Swiss-inspired composition balances academic rigor with modern visual energy; contrast and hierarchy can support learning and recall; a grid keeps a large concept inventory organized; and progress plus quiz feedback creates a more engaged study loop.

## Current Direction: Neural Garden

The current upgrade evolves the most useful parts of these directions into Neural Garden. It keeps module identity and clear study hierarchy but replaces the dark technical aesthetic with a high-key, lilac, mineral-blue, mint, and coral learning environment. The result uses a cognitive constellation, gentle depth, and reduced-motion support to make study feel memorable without distracting from the course material.
