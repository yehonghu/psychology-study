# PsychMind Upgrade Blueprint

## Product Role

PsychMind is an interactive study environment for foundational psychology. Its value is not simply content coverage: learners move from an overview of the mind, through short recall moments, into chapter-level concept practice and a scored quiz. The upgrade must preserve that path while making it feel more memorable, calm, and self-directed.

## Visual Direction: Neural Garden

PsychMind will deliberately avoid both the portfolio’s cinematic dark interface and BookEase’s warm editorial board. **Neural Garden** is a high-key, immersive learning environment: misty lilac, mineral blue, soft mint, coral signals, translucent pearlescent surfaces, and organic neural arcs. It should feel like entering an illustrated field guide to the mind rather than opening a corporate dashboard.

The central hero object is a floating constellation of learning layers. Individual modules read like luminous specimens in orbit; their position shifts subtly with pointer movement and with page progress. Rounded depth, diffused shadows, gradients, and low-contrast biological lines create artistry without reducing text clarity.

## Interaction System

| Surface | Interaction | Learning purpose |
|---|---|---|
| Page frame | Soft progress filament and translucent navigation | Shows the learner’s movement through a long overview. |
| Hero | Pointer-responsive cognitive constellation with layered topic tiles | Turns the curriculum into a visually memorable whole. |
| Scroll narrative | Gentle float, focus bloom, and staggered section entries | Makes transitions between overview, modules, and quiz preparation intentional. |
| Module cards | Controlled 3D tilt, color-specific glow, and progress affordance | Makes chapter choice feel active without behaving like a game. |
| Learning path | Connected neural nodes that light in sequence | Explains course progression from foundations to application. |
| Reduced-motion mode | Stable cards and static visual hierarchy | Supports learners who request less motion. |

## Scope

1. Retain all existing routes: home, chapters index, chapter detail, and quiz.
2. Rebuild the global visual tokens, navigation, public home, and supporting module presentation around Neural Garden.
3. Preserve existing chapter data, flashcard mastery behavior, quiz generation, feedback, and score logic.
4. Translate the two remaining Chinese input-composition comments so all tracked source text is English.
5. Publish a static GitHub Pages build as a direct interactive preview. The application is static by design; no external database is required for its core learning flows.
